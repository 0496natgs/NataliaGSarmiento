# Photographs by René Rivas

Aerial and landscape photographs by René Rivas (https://renerivas.xyz/), used on this site with his
permission. Any cover or hero image taken from this folder is credited automatically as
"Photograph: René Rivas", linked to his site (see `PHOTO_CREDITS` in
`quartz/components/sections/sectionsConfig.ts`).

To use one as the cover of a piece, add to its front matter:

    cover: /static/photos/rene-rivas/rene-rivas-dji-0063.jpg

Keep the file names as they are: they match his originals (DJI_0063, DSC0757, …).
